🚀 运行方式

步骤命令
1. 启动数据库cd code/tianyin-platform && docker compose up -d
2. 初始化后端cd backend && cp .env.example .env && pnpm install && pnpm run prisma:migrate && pnpm run prisma:seed
3. 启动后端pnpm start:dev（http://localhost:3000/api）
4. 启动前端cd ../frontend && pnpm install && pnpm dev（http://localhost:5173）
